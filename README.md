# Source_Code_Window_Frequency_Caching
Deterministic MEC framework integrating online task offloading with Window Frequency (WF) caching for latency-energy optimization and deadline-aware execution in multi-tier Mobile Edge Computing systems.

Repository Contents:

1. Python implementation of both proposed algorithms:

   * Online Offloading and Cache-Update Procedure
   * Window Frequency (WF) Cache Update (per layer)

2. The parameter values used in the code are selected only for demonstrating and explaining the working flow of the algorithms.

3. A PDF document is also included containing the detailed explanation of the algorithms and their step-by-step workflow.
